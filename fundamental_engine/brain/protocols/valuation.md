# Choose the valuation model for the economic claim

Start by asking which cash flows/assets belong to holders and how they can be valued.
Supported: nonfinancial FCFF DCF, growth-linked reinvestment, reverse DCF and a finite
ownership/financing model. Financial institutions, complex conglomerates, biotech
binary outcomes, NAV and SOTP require dedicated work not implemented by the calculator.
A playbook allows research of these firms; it does not unlock an unsupported formula.

Construct bear/base/bull paths from business drivers, not arbitrary percentage bands.
For each path link demand -> revenue -> margins -> reinvestment -> cash -> funding
-> diluted ownership. State the source versus judgment for each material assumption.
Normalize cyclical earnings before extrapolation. Include decline and capital loss
where the economics warrant; a perpetuity is not mandatory for every business.

Inspect value dependence on terminal value, growth/margins, capital efficiency,
discount rates and financing. Use ranges and scenario differences. Explain what
has to be true for a valuation, which assumption matters most and what would break it.

Match enterprise/equity bridges, currency, lease treatment, share class and dates.
Reported annual revenue is not automatically the correct base at a much later
valuation date; prepare a reviewed stub/starting forecast when material.

A good business can be expensive. A low multiple can reflect declining earning power.
Never solve an attractive price by changing assumptions without new justification.
Store the actual calculator inputs/results so later reviews can reconstruct them.
