# ServiceNow (NOW) run — 2026-09-28: notes, fixes and Cowork test plan

A process record, NOT a price target. The first full real-company run of v0.9.1,
executed in a Claude Code cloud session (not Cowork). Regression input:
`examples/real/now_drivers_2026q3.json`.

## What was run

research data (AV statements/overview/treasury, IB quote, web search) ->
import_statements -> classify_company (high_growth / fast_grower, acquisition flag)
-> annual valuation (bear/base/bull through 2035, reported to 2031-12-31) ->
valuation_audit (internally_reconciled) -> research_review
(ready_for_conditional_synthesis) -> plain_verdict -> research_checkpoint.

Executed result at $131.25 (IB realtime): base ~$95, bear ~$50, bull ~$130 per share
today; base 2031-12-31 ~$124. Cost of equity 9.75% (10y UST 4.99%). The price
implies ~8.1% cost of equity on base cash flows, or ~+4.6pt extra growth every year
2027-2035 at fixed margins. Base 2027 revenue within 0.4% of consensus ($19.16B).

## Lessons for real runs

- Record how each source was obtained. A vendor number that matches a search
  excerpt is consistent, not read. Only a read filing earns `primary_document`.
- Alpha Vantage hit a rate limit after ~6 quick calls (message cited 25/day on a
  free key). Budget 6-8 calls per company; save big payloads to file and use
  import_statements instead of reading them into context.
- SBC-heavy software: charge SBC as a cost (cash_equivalent). Reported FCF margin
  guidance (35%) and model owner cash differ by SBC; reconcile, don't mix them.
- Acquisitions (Armis $7.8B) change debt, goodwill, amortization and growth mix;
  bridge the balance sheet and keep recurring tuck-ins as growth capex.
- Say which single input dominates. For NOW it is the required return, then growth
  duration after 2030; near-term revenue matches consensus.
