# העברת התמונה הפונדמנטלית לסשן שמשרטט (מ-13.11.2026)

**חלוקת העבודה (החלטת הבעלים):**
- **הריפו הזה:** מביא רק את התמונה הפונדמנטלית.
- **הסשן המקומי ב-TradingView:** עושה את כל העבודה הטכנית: אזורים, נגיעות, ATR, חוזק יחסי, משטר שוק, ומה מוצג על הגרף.

**איפה:** `research/technical/<TICKER>/<תאריך>/fundamental.json`. קובץ חדש נכתב אחרי כל הערכת שווי, או אחרי עדכון מדוח.

## השדות
| שדה | מה יש בו |
|---|---|
| `ticker`, `as_of`, `price`, `price_time_utc` | המחיר שעליו נבנתה ההערכה |
| `verdict_he` | המסקנה: קנייה / החזקה / לא לקנות במחיר הזה, ולמה (משפט אחד) |
| `buy_test_price` | המחיר שמתחתיו התרחיש הבסיסי נותן 12% בשנה ומעלה (קו ההחלטה הפונדמנטלי) |
| `margin_of_safety_price` | מחיר כניסה עם מרווח ביטחון (13% בשנה), אם חושב |
| `values` | שווי היום ובעוד שנה / 5 שנים, לפי תרחישים דובי / בסיסי / שורי, והשווי המשוקלל |
| `scenarios` | לכל תרחיש: הסתברות (שיקול דעת) ומשפט קצר על התנאי שלו |
| `annual_return_pct` | תשואה שנתית לכל תרחיש, ובעדשה השנייה |
| `conditions` | התנאים לפעולה: להוסיף / לקצץ / לצאת, עם מספרים ומקור |
| `next_report` | תאריך הדוח הבא, אם הוא מאושר, ומה לבדוק בו |
| `thesis_link` | קישור לתזה המלאה ב-research/companies |
| `notes_he` | עד 3 משפטים שחשוב שהגרף יידע (למשל: "הכול תלוי במחיר השכרת שרתי AI") |

## כללים
- **זה מחקר על החברה בלבד.** אין בקובץ כמויות, עלויות או נתונים מהתיק.
- **השווי הוא ערך כלכלי לפי המודל,** לא מחיר שהמניה בטוח תגיע אליו.
- **התאמות פונדמנטליות שמגיעות מהשרטוט:** אם הסשן המשרטט מוצא שקו פונדמנטלי נופל בתוך אזור טכני, או שהשניים סותרים, הוא כותב את זה בצד שלו. הקובץ הזה לא משתנה בגלל הגרף.
