# Fundamental Engine

מנוע מחקר פונדמנטלי ופוטנציאל מוקדם · גרסה 0.1.0

מנוע Python רץ, ללא תלות בחבילות חיצוניות בזמן הרצה. מפריד בין מצב פיננסי נוכחי, ראיות לפוטנציאל עתידי, הערכת שווי ומסלול מימון. הפסד נוכחי אינו מוחק ראיות לאימוץ מוצר או לשיפור העסק.

**מעמד:** גרסת ליבה ראשונה שנבדקה בנתונים סינתטיים. אינה מערכת מחקר אוטונומית מלאה, אינה המלצה לקנות ואינה תחזית מכוילת. מאגר הקוד: https://github.com/yarinlavi1-source/fundamental-engine

## הרצה בשתי פקודות

נדרש Python 3.11 ומעלה. מתוך תיקיית הפרויקט:

```bash
python -m unittest discover -s tests -v
python -m fundamental_engine analyze examples/emerging_demo.json
```

הפקודה מחזירה נתיב מוחלט ל־`report.html`. פותחים את הקובץ בדפדפן. לצד הדוח נוצר JSON ושמורה גרסה מלאה ב־SQLite. ההדגמה משתמשת בחברה ובמספרים **מומצאים**; הדוח מסומן כך בבירור.

אפשר להתקין את פקודת `fundamental` באמצעות `pip install -e .`, אך אין צורך בכך להרצה מתיקיית הקוד.

## מה עובד

- בדיקת קלט, מטבע, יחידות, תקופות ומקורות.
- יחסים פיננסיים, צמיחה שנתית, FCF מדווח ומעקב אחר SBC.
- עזרי YTD לרבעון ו־TTM עם בדיקות חפיפה והפרדה ממאזנים.
- DCF לחברות לא־פיננסיות מתאימות, גשר משווי פעילות לשווי מניה ורגישות ל־WACC.
- Reverse DCF לצמיחה קבועה, עם גילוי אילו הנחות מוחזקות קבועות.
- תרחיש מזומן שמזהה מתי נדרש מימון נוסף.
- מפת פוטנציאל בחמישה ממדים: שוק, אימוץ, יתרון, ביצוע וכלכלת יחידה.
- הפרדת ראיות תומכות, נגדיות, לא מאומתות וישנות; אין ציון קסם או הסתברות מומצאת.
- אבני דרך, תנאי הצלחה וכשל, תזה וטיעון נגדי שסיפק האנליסט.
- גרסאות מחקר שאינן נדרסות והשוואת ריצות.
- מתאם SEC עם מטמון, שמירת גיבוב מקור וחילוץ תגית מדויקת לפי תאריך.
- דוח HTML בעברית עם פירוט החישובים והמקורות.
- בדיקות אוטומטיות ו־GitHub Actions מוכנים למאגר.

## מה עדיין דורש הרחבה

- SEC אינו הופך אוטומטית כל חברה לקלט מנורמל. חילוץ תגיות זמין; התאמתן, ביאורים ומגזרים דורשים סקירה.
- אין עדיין חיבור LLM/API או שרת MCP. `CLAUDE.md` מתאר כיצד Claude יכול לעבוד עם הקוד והקלט.
- אין משיכת מחירים, תמלולים או תוכן יוצרים אוטומטית.
- אין מודלים ייעודיים לבנקים, ביטוח, REIT וביוטק מוקדם; DCF נחסם עבורם.
- מסלול המימון נפרד מה־DCF. גיוס מניות עתידי ודילול ממימון אינם מתווספים אוטומטית.
- אין מודל מס מלא, NOL, אופציות עובדים מלא, ADR או תמיכה בריבוי מטבעות.
- אין הוכחת תשואה היסטורית, כיול הסתברויות או המלצת משקל תיק.
- מתאם SEC נבדק במבחני חילוץ; קריאת רשת חיה לא נבדקה בסביבה שבה נוצר הפרויקט.

### SEC

ה־API ציבורי ללא מפתח. יש להגדיר פרטי קשר אמיתיים במחשב שלך, לא להכניס סודות לקוד:

```bash
export SEC_USER_AGENT='ResearchEngine your-email@example.com'
python -m fundamental_engine sec-fetch 320193
python -m fundamental_engine sec-extract runs/sec/CIK0000320193.json --tag RevenueFromContractWithCustomerExcludingAssessedTax --unit USD --as-of 2026-09-26
```

הטיקר אינו משמש לניחוש CIK. יש לספק CIK נכון; שם התגית משתנה בין חברות. הפקודה לא מחליפה תגיות בשקט. `--refresh` מוריד עותק חדש, והעותק בעל גיבוב התוכן נשמר בנפרד. המטמון אינו מתרענן אוטומטית; המשתמש אחראי לרעננו בעת פרסום חדש.

מקורות SEC: [API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces), [מדיניות גישה](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data).

## עבודה על חברה אמיתית

1. העתיקו את קובץ הדוגמה לקובץ חדש.
2. החליפו **כל** מקור ונתון סינתטי, ולא רק את הטיקר.
3. הזינו מספרים ביחידות מלאות: 50 מיליון הם `50000000` ולא `50`.
4. קבעו תאריך מחקר, מטבע אחד ומקורות עם תאריך זמינות.
5. הזינו דוחות שנתיים GAAP שאינם חופפים. נתון חסר הוא `null`.
6. הגדירו תרחישים, מדיניות SBC, הון ומסלול מזומן. כל הנחה צריכה נימוק.
7. הוסיפו ראיות לפוטנציאל ואבני דרך. `supported` פירושו שהאנליסט בדק, לא שהמנוע אימת אוטומטית.
8. הגדירו `is_demo=false` רק אחרי שהחלפתם את הנתונים הסינתטיים.
9. הריצו `validate`, ואז `analyze`. קראו את פערי המידע לפני טווחי השווי.

## חישוב שווי ופוטנציאל

מודל ה־DCF משתמש ב־`FCFF = EBIT − cash operating tax − reinvestment`. `reinvestment` כולל CapEx פחות D&A בתוספת גידול בהון חוזר תפעולי והתאמות השקעה עקביות. בגרסה זו הוא מוגבל לאי־שליליות. הוא **אינו** CapEx ברוטו של מסלול המימון.

כל שנת תחזית היא שנת מודל יחסית לתאריך ההערכה. ההכנסה השנתית האחרונה משמשת בסיס, לא תחזית אוטומטית לשנת הכספים הנוכחית. אין טיפול בתקופת stub; נדרש עדכון בסיס ותחזית בידי האנליסט כאשר פער התאריכים מהותי.

המרווח התפעולי כבר כולל את העלות הכלכלית של SBC עתידי. הזכויות שכבר קיימות מיוצגות בקלט `share_equivalents`; זהו קירוב מפורש ולא שווי אופציות מלא. אין להוסיף שוב דילול עתידי עבור אותו SBC. תוצאת שווי אינה תחזית תשואה ואינה מחיר יעד לשנה עתידית.

הצמיחה ב־Reverse DCF נפתרת תחת מרווחים והשקעה מחדש מוחלטת קבועים. זו רגישות מתמטית, לא הוכחה שההשקעה הקבועה יכולה לממן את הצמיחה. יש לבדוק תרחיש השקעות תואם לפני שימוש במסקנה.

סטטוס `financing_required` גובר על עצם קיומו של שווי DCF. תוצאות השווי נשארות לצורך בדיקת הנחות, אך אינן כוללות פתרון למימון החסר. אין להציגן כשווי של תזה ממומנת.

פוטנציאל אינו נפסל בשל הפסד, אך גם אינו הופך להמלצת קנייה. ממד ללא ראיות מסומן כחסר; אין מילוי מהזיכרון של המודל.
